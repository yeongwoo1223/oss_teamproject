# Team rules (examples)

- Pull request size: one function or one fix, about 100 changed lines
- Review: two reviewers, within 48 hours. A `blocking:` comment stops the merge
- Merge: the reviewer presses the button, "Create a merge commit", delete the branch
- Branch names: `feat/<name>`, `fix/<name>`, `docs/<name>`, `chore/<name>`
- AI use: disclosed in the `## AI use` section of every pull request
